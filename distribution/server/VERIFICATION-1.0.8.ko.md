# 1.0.8 정식 릴리즈 검증 — 2026-11-05

사용자가 공개 릴리즈를 설치해 Mac 실기기 테스트를 진행하기로 했으므로, 해당 시험을
정식 게시의 선행 조건으로 두지 않는다. **정식 릴리즈라는 표시는 모든 플랫폼 검증을
마쳤다는 뜻이 아니다.** Mac 설치·최초 신뢰·절전/로그인 복귀, native Windows는 미검증이다.

## 이전 실호출 검증과 코드 동일성

Claude CLI·Codex CLI·Jev로 수행한 저장 판단·출처 통합·수정·삭제·두 기기 회상·공유 해제
검증은 [후보 버전의 실제 실행 기록](VERIFICATION-0.3.0rc1.ko.md)에 보존돼 있다.
1.0.8의 코어 CPython 3.12/3.13 휠과 SDK의 실행 파일을 해당 후보 휠과 바이트 단위로
비교했다. 버전 표기용 __init__ 및 배포 메타데이터를 제외한 **기억 처리 코드는 동일**하다.
`PROMOTION-PARITY.json`에 비교 파일 수와 판정을 남겼다. 모델 검사를 모두 새로 실행한
것처럼 통과 횟수를 합산하지 않는다.

## 1.0.8에서 새로 실행한 검사

- 실제 Jev 인증 확인과 설치 패키지 시작: `version=1.0.8`, ready=true,
  generation_enabled=false, integration_enabled=true.
- 기존 플러그인 `agents-memory-local`과 `agents-memory-unified`의 실제 stdio 초기화·도구
  조회·setup_status. 미설정 때는 안내만 제공하며 가짜 저장 성공을 반환하지 않는다.
- 설치·기존 native DB 업데이트 중 키·모델·주소·세 앱 설정·대기 의도 보존. DB와 서비스를
  모두 끈 뒤 MCP 연결으로 다시 시작하고 실제로 처리된 기억을 회상했다.
- 기존 설치/DB 호환 검사 59건, 이전 설치 인자를 새 설치기로 전달하는 검사 3건.
  기존 플러그인 이름의 초기화·설정 완료 검사 2건, 별도 이름의 동일 검사 2건.
- 기존 local-llm / judge-host 인자를 Claude/Codex 선택으로 변환하고 공백 있는 경로를
  그대로 전달한다. 생성 모델 가중치를 새로 설치하는 공급자는 추가하지 않았다.

## 배포와 남은 범위

SDK·코어·플러그인·설치기·setup_status 버전은 모두 1.0.8이다. 기존
`agents-memory-local@agents-memory`를 업데이트해 사용할 수 있다. 다른 이름인
`agents-memory-unified`를 같은 프로젝트에 중복 등록할 필요는 없다.

1.0.7 standalone runtime과 이전 사용자 데이터는 삭제하지 않는다. 새 공통 엔진으로
처음 바꾸는 경우 한 번 설정하고, 기존 데이터의 계정/프로젝트 귀속과 이전 계획을
검토한다. 과거 원문의 자동 재처리·삭제를 하지 않았다. 이미 공통 엔진을 설정한
사용자의 키·설정·DB는 업데이트 시 보존한다.

Mac 의존성 잠금 파일은 후보 버전과 동일하며 Apple Silicon Python 3.13용 wheel 다운로드
검증을 통과했다. 실제 Mac 실행의 증거는 아니다. OMP에서는 입력 수집·문맥 전달을
검사했으며 외부 답변 모델의 성공을 이번 검사로 주장하지 않는다. 서버 운영자는 원문을
읽을 수 있으며 E2EE가 아니다. 서버 부팅 서비스 설정과 실제 사용자 데이터 이전은 별도다.

GitHub 첨부 업로드 API의 인증 오류 때문에 검증 파일은 같은 공개 저장소의 고정 커밋에
게시한다. 설치기는 해당 번들의 SHA-256을 검증한다. release 본문의 링크에서 검증 파일을
받을 수 있다. GitHub Actions·유료 리소스 생성·기존 사용자 서버 변경은 하지 않았다.
