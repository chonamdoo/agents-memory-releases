# 0.3.0rc1 검증 기록 — 2026-11-05

이 배포는 Linux x64 합성 데이터 검증을 통과한 릴리즈 후보다. Mac 실제 설치·최초 신뢰·
로그인/절전 복귀를 증명하지 않으므로 기존 stable을 대체하지 않는다. SDK 상태의
`version=0.3.0rc1`은 GitHub 태그 `v0.3.0-rc.1`에 대응한다.

## 실제 실행과 계약

| 대상 | 실제 확인 | 증거 |
|---|---|---|
| Claude CLI | 설치된 CPython 3.13 코어 → 실제 CLI 판단·생성 → Hindsight 추출/통합 → 두 PC 회상·수정·삭제 | `publish-claude.xml`, `claude-local-product.json` |
| Codex CLI | 같은 제품 경로, Codex만 호출 | `publish-codex.xml`, `codex-personal-server-product.json` |
| Jev | 실제 typed API → 원문 보존 사실 통합 → 두 PC 회상·수정·삭제 | `publish-jev-local.xml`, `jev-local-product.json` |
| 저장 거절 | 세 실제 공급자로 인사말 입력이 최종 기억/검색에 들어가지 않음 | `rejection-*.xml`, `*-rejection.json` |
| 배치 모드 | local/personal-server/team-server/company-server의 공통 경로, 사용자·프로젝트·팀 공유 경계 | `final-six-product-paths.xml`, 서버 모드 JSON |
| 자동 이벤트 | 실제 Linux Claude·Codex 훅은 표식을 회상, 훅 없는 대조에서는 회상하지 못함 | `native-hosts-publish.xml`, `native-hosts.json` |
| OMP | 18.16.0 실제 before_agent_start 수집·문맥 출력 | `native-omp.json`; 외부 답변 모델 성공을 주장하지 않음 |
| 설치·업데이트 | 새 prefix native DB/E5 자동 준비, 기존 공급자/모델/키/주소/기기/세 앱 설정 보존, 대기 의도 처리 | `installer-lifecycle-publish.xml`, `installer-lifecycle.json`, 신규 설치 상태 |
| 자동 시작 | DB·서비스를 모두 중단한 뒤 MCP 초기화와 소유 서비스 재시작·실제 회상 | 같은 lifecycle 증거 |
| 원격 thin 클라이언트 | 로컬 Hindsight·Jev 키 없이 서버 처리·백그라운드 전송·회상 | `thin-client.xml`, `thin-client.json` |
| 플러그인 | 미설정 시 MCP 연결 유지·setup_status 안내·가짜 저장 성공 없음, 설정 후 실제 SDK 실행 | `plugin-protocol-final.xml` |

실제 요청 모델은 `claude-fable-5-1`, `gpt-6.1-terra`, `jev-1.14.0`이다.
CLI 서비스 내부의 모델 라우팅까지 독립적으로 증명하는 주장은 아니다. 별도 생성 모델
가중치를 설치하거나 선택하지 않은 공급자로 fallback하지 않았다.

두 근거의 통합, 같은 작업 ID 재전송 시 변경 중복 없음, revision 수정, 현재 출처 검증,
공유 해제 후 새 검색/brief 차단, 한 출처 삭제 뒤 다른 출처 회상과 전체 삭제 후 검색
제외를 제품 경로에서 확인했다. 모델 출력 문자열의 일치를 요구하지 않았다.
Jev는 같은 대상·속성의 호환 근거를 typed 판단으로 묶되 원문 인용을 모두 유지한다.
상충·시점 차이·불확실성은 자동으로 한 값으로 만들지 않는다.

## 회귀·독립 검사

- 공통 코어·공급자·취소·경계·통합 선택 검사 139건 통과. 가짜 확률로 상충·불확실한
  사실이 합쳐지지 않는지 검사하며, CLI 자식의 DB/기억 키 제거와 네트워크 guard 유지도 확인했다.
- 서버 회귀 93건 통과와 빠졌던 네이티브 프록시/휠 포함 파일 2건 별도 통과.
  일부 공급자 제어 흐름은 명시적인 테스트 대역을 사용하며 실제 모델의 품질 증거와 구분한다.
- PostgreSQL/pgvector, 실제 Hindsight 1.1.0, 고정 E5를 사용했다. 초기 계약의 ACK 유실,
  커서·복원·충돌 격리·권한·상태 기반 검사 자료도 로컬 검증 자료에 보존한다.
- 마지막 삭제 처리 보완 이후 설치된 SDK로 세 공급자를 다시 실행했다. 한 근거 삭제가
  나머지 관찰을 무효화하면 살아 있는 근거로 재통합한 뒤 삭제 확정을 공개한다.
- 정해진 사실 조건을 검사한 합성 사례다. 검색 품질 전반·모든 자연어 충돌·임의 장애 조합을
  증명하지 않는다. 일부 통과 검사를 중복 실행했으므로 횟수를 합쳐 품질 점수로 쓰지 않는다.

## 고정·재실행

릴리즈의 `SNAPSHOT.json`은 공개 소스 커밋, 비공개 코어 커밋과 소스 파일 해시,
공개 파일/잠금 파일 해시, 최종 번들·휠 해시를 기록한다. 원본 비공개 정책 소스,
실제 키·OAuth 파일·사용자 데이터·런타임 DB·개인 로그는 업로드하지 않는다.
`BUILD-core-312.json`, `BUILD-core-313.json`으로 실행 코어가 소스 스냅샷에 대응하는지
확인한다. 코어는 CPython minor별 sourceless bytecode이며 암호화가 아니다.

`agents-memory-verification-0.3.0rc1.zip`에는 비밀값 없는 XML/JSON과 재실행 명령 및
합성 검증 코드만 포함한다. 실제 CLI/모델 경로는 해당 호스트의 인증과 검증용 PostgreSQL이
필요하다. `REPLAY.md`는 보존된 환경의 정확한 경로와 다른 환경에서 바꿀 항목을 구분한다.

## 남은 한계와 안정판 조건

- Mac 실기기 설치·업데이트·최초 앱/훅 신뢰·로그인/절전 복귀는 사용자 확인이 남았다.
  Mac wheel 의존성 다운로드 가능 여부와 실제 Mac 실행은 별개다.
- native Windows는 미지원 검증 상태다. WSL2 안내는 Linux 경로이며 이번 시험에서
  Windows 호스트 자체를 실행해 증명하지 않았다.
- OMP의 외부 답변 모델은 의도적으로 유효하지 않은 시험 키를 사용했다. 확장 수집·회상
  문맥은 실제로 확인했지만 답변 모델의 최종 답변 성공을 주장하지 않는다.
- 훅은 현재 사용자 입력/세션 이벤트를 처리한다. 모든 세션 이력·도구 출력을 자동 수집하거나
  작업 요약 전체를 생성하는 기능은 아니다. team_brief는 허용된 기억의 짧은 발췌다.
- 서버 재부팅용 systemd user unit과 Mac 로그인 서비스는 운영 설정이다. 이번 컨테이너는
  OS 부팅을 시험하지 않았다. 로컬 MCP 재연결에 의한 DB/서비스 재시작은 실제 검증했다.
- 서비스 사용자별 선택 공급자 하나를 사용한다. 회사용 SSO·SCIM·사용자별 LLM 키 분배를
  지원한다는 뜻이 아니다. 서버 운영자는 원문을 읽을 수 있으며 E2EE가 아니다.
- 처리 중 SQL과 Hindsight는 분산 원자 트랜잭션이 아니다. 의도/준비 결과를 보존해 재시도하며
  색인 교체 동안 일시적으로 검색 가용성이 줄 수 있다. 과거 로그·백업의 원문 파기는 별개다.
- 기존 사용자 서버·Mac·기억·키는 변경하지 않았고, 구버전 데이터의 자동 재처리를 하지 않았다.
  실제 과거 데이터 이전은 읽기 전용 계획과 복구 방법을 검토한 뒤 명시적으로 수행해야 한다.

안정판 승격은 위 Mac 설치/업데이트와 실제 일상 세션의 자동 기억·회상 확인, 비밀값 보존,
동일 버전 표시를 통과한 뒤 판단한다. 새 실패가 나오면 후보를 유지하고 재현부터 남긴다.
GitHub Actions·유료 리소스 생성·실제 사용자 데이터 재분류는 실행하지 않았다.
