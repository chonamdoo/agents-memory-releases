# 공통 Hindsight 기억 게이트웨이 — 0.3.0.dev1

현재 소스는 로컬·개인·팀·회사 서버가 같은 기억 처리 계약을 사용하는 미배포 수정안입니다.

- [공통 런타임·공급자·세 앱 연결·이전 안내](UNIFIED-RUNTIME.ko.md)
- [구현 전에 작성한 동작 계약](MEMORY-CONTRACT.md)
- [이전 0.2.1 서버 안내(역사 자료)](README-0.2.1.ko.md)

`received`는 저장 후보 접수이며 처리 완료가 아닙니다. 공급자 판단과 근거 구간 선택,
Hindsight 저장·재조회 이후에만 `ready` 기억을 공개합니다. 기존 원문·키·설정은 보존하고,
이전 데이터의 재처리는 명시적으로 선택합니다.

이번 작업은 소스 수정과 격리된 합성 데이터 검증까지입니다. 기존 공개 릴리즈·사용자 서버는
업데이트하지 않았습니다. 새 코어 배포 패키지와 플랫폼별 새 설치/업데이트 검증이 끝나기
전에는 정식 설치 완료나 출시 가능 상태로 표시하지 않습니다.
