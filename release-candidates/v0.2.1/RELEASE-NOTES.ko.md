# v0.2.1 — 개인형 MCP 정식 배포

검증된 Linux x64 서버와 Mac 클라이언트를 대상으로 한 개인형 MCP 배포입니다. 개인 로컬 설치는 안정판 1.0.7을, 본인 서버 연결은 0.2.1을 사용합니다.

- **개인 로컬:** 기존 안정판 1.0.7 설치기로 연결합니다. 저장 판단에는 기존 로컬 LLM 연결 또는 Jev를 선택하고, 기억과 E5 검색 임베딩은 PC에서 운영합니다. 생성 LLM 가중치는 묶어 설치하지 않습니다.
- **본인 서버 연결:** 본인이 준비한 서버 주소와 일반 기기 키로 연결합니다. 같은 계정의 여러 PC가 기억을 동기화하고 PC별 키를 회수할 수 있습니다. 클라이언트 버전은 0.2.1입니다.
- **서버 운영:** 본인의 Linux x64 서버에서 Docker Compose로 PostgreSQL·pgvector·API/MCP·E5를 운영합니다. 이 설치기는 GCP 등의 자원이나 결제 계정을 만들지 않습니다.

세 앱별 설치·승인·확인·업데이트 절차: [MCP-INSTALL.ko.md](MCP-INSTALL.ko.md).

저장 위치와 판단용 LLM은 별개입니다. 현재 Cloud MCP 직접 저장 경로는 앱에서 선택한 내용을 저장하며 Jev나 기존 Hindsight 자동 정제를 별도로 호출하지 않습니다. 기존 로컬 판단을 거친 기억을 서버로 보내려면 문서의 선택형 Hindsight 내보내기를 사용합니다. 대화 전체 자동 업로드나 클라우드 기억의 Hindsight DB 자동 병합을 제공하는 것으로 해석하면 안 됩니다.

## 설치

첨부된 `agents-memory-personal-0.2.1.zip`과 `SHA256SUMS`를 내려받아 체크섬을 확인하고 압축을 풉니다. 압축 안의 설치기를 터미널에서 실행합니다. 배포 폴더 전체가 필요합니다.

```sh
bash distribution/install.sh
```

또는 실제 작업 프로젝트에서 옵션으로 선택합니다. 아래 경로는 압축을 푼 배포 폴더의 절대 경로로 바꿉니다.

```sh
# 개인 로컬: 이어지는 기존 설치 과정에서 로컬 LLM 또는 Jev 선택
bash /absolute/release/distribution/install.sh --mode local \
  --client claude --client codex --client omp --project "$PWD"

# 본인 서버 연결: 서버 주소와 기기 키 설정
bash /absolute/release/distribution/install.sh --mode personal-server \
  --client all --profile personal --project "$PWD" \
  --project-name my-project --url https://YOUR_HOST
```

서버 주소는 실제로 접근 가능해야 합니다. 비밀 키는 숨김 입력 또는 비공개 연결 파일로 전달합니다. 개인 IAP SSH 연결을 사용하는 경우 각 PC의 루프백 포워딩을 먼저 준비합니다. 설치기가 IAP 로그인이나 터널 자동 시작을 자동 구성하지는 않습니다.

직접 서버를 설치하려면 `distribution/server/README.ko.md`와 `CONTRACT.md`를 읽고 해당 서버에서 `bash bootstrap.sh`를 실행합니다. 서버 관리자 키는 서버에 보관하고 각 PC에는 일반 기기 키를 발급하세요. 현재 안정 로컬 플러그인은 자동으로 클라우드 모드로 전환되지 않습니다. 설치 모드 변경만으로 기존 기억을 자동 이전하지 않습니다.

업데이트는 같은 설치 모드·프로필·프로젝트로 재실행합니다. 기존 연결 키와 SQLite를 보존합니다. 데이터 볼륨 삭제나 새 계정 생성은 업데이트 절차가 아닙니다. 최초 앱 신뢰 승인은 별도로 필요할 수 있습니다. Codex의 전역 권한 설정이 서버별 승인보다 강하게 작동할 수 있으므로, 일상 사용에 복구/충돌 해결 도구가 필요 없다면 이 서버의 `disabled_tools`로 제외할 수 있습니다.

## 확인한 범위

- 고정 소스·실제 PostgreSQL/pgvector·E5·두 replica·HTTP 장애 주입·설치된 stdio MCP의 자동 검사 64개 통과.
- Hypothesis: seed 20261104, 20개 예제·400개 동작·확인 응답 유실 83회. 모든 동시 실행 순서를 증명하지는 않습니다.
- 기존 로컬 회귀와 설치 모드 분기·인수 보존·잘못된 모드 거부 검사를 합해 136개 및 하위 검사 62개 통과. 선택기 신규 검사는 9개입니다.
- Linux x64에서 0.2.1 Docker 이미지 빌드·읽기 전용 루트 기동·동기화·검색·공유 회수 검증.
- 사용자가 제공한 Ego 보고: GCP 개인 VM에서 서버 0.2.0 운영, Mac에서 클라이언트 0.2.1 업데이트 시 키·데이터 유지, macOS /var 경로 처리, 실제 기억 왕복과 삭제, 터널 종료/VM 재부팅 후 재연결 및 기억 보존 확인. 이 항목은 이 실행 환경의 독립 검증과 구분합니다.
- 사용자 보고 기준 Codex 대화형 MCP 연결, OMP 연결, Claude 비대화형 설정 로드 확인. Claude 최초 대화형 폴더 신뢰 확인은 남아 있습니다.

Native Windows, Mac 로그인·잠자기·네트워크 변경 후 복구, 깨끗한 OS 설치, 외부 HTTPS 운영, 부하·HA·검색 품질은 검증 범위 밖입니다. terminal-mac은 이번 검증 범위에 포함하지 않습니다. 기존 로컬 설치기의 지원 범위는 Apple Silicon macOS 15+이며, 이 릴리즈가 지원 OS를 자동 확대하지 않습니다.

## 운영 시 알아둘 점

서버 운영자는 업로드한 내용을 읽을 수 있습니다. 삭제는 현재 검색 제외와 tombstone 전파이며 과거 로그·백업·복구 보관본의 영구 파기와 다릅니다. 백업 복원 후에는 접근을 열기 전에 epoch 변경·기존 키 회수·재발급 절차가 필요합니다.

이 릴리즈는 개인 서버 MCP 0.2.1의 정식 배포입니다. 기존 안정 로컬 릴리즈 v1.0.7은 보존하며 별도 버전으로 관리합니다. GitHub Actions는 실행하지 않았으며, 추가 유료 인프라를 생성하지 않았습니다.
