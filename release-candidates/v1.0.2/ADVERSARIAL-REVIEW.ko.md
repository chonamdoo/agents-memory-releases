# Astra 적대적 검토 — 1.0.2

검토 범위: 선택형 Claude/Codex JSONL 후보 파서, 저장 원장과 HTTP 문서 매핑, 명시적 CLI, 합성 회귀 테스트. 실제 사용자 이력은 사용하지 않았습니다.

검토에서 재현한 릴리즈 차단 사항 세 건을 수정했습니다.

1. Codex session_meta의 프로젝트만 검사하던 경계를 보강했습니다. 파일 내 명시 cwd가 다른 프로젝트이면 파일 전체를 거부합니다.
2. response_item의 user role만으로 인간 작성으로 간주하던 대체 경로를 제거했습니다. canonical event_msg.user_message만 후보가 됩니다.
3. 총량 제한으로 읽지 못한 파일을 증분 캐시에 넣던 오류를 수정했습니다. 성공한 파일만 캐시하고 제한 도달은 미완료로 보고합니다.

Astra가 수정점과 신규 회귀 세 건·관련 정상/원문 변경 검사 두 건을 재검토해 5개 통과, 해당 범위 추가 차단 사항 없음으로 확인했습니다. 전체 신규 41개는 소스 및 설치된 Linux 바이너리에서도 통과했습니다.

이 검토는 비용 절감률·모델 품질·모든 CLI 로그 버전·macOS 실기 실행을 입증하지 않습니다. 자동 tool pruning/stop/hook 변경을 제외하고, 원문 전송과 저장을 명시적으로 분리한 수동 기능으로 배포합니다.
