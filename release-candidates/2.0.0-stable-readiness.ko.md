# v2.0.0 정식 출시 준비 — 2026-11-07

현재 공개 v2.0.0은 prerelease다. 이 변경은 검색 결과의 중복 근거 처리를
수정하며, 정식 출시나 독립 품질 평가 통과를 의미하지 않는다.

## 수정한 검색 결함

Hindsight의 원문 사실과 통합 observation이 같은 내용을 반환할 때, 출처별
대표 ID가 다르면 동일 내용이 결과 제한을 중복 점유했다. 또한 여러 줄짜리
근거의 중복 여부를 줄 목록과 비교해 같은 본문을 반복해서 이어 붙였다.

현재 SQL에서 접근 가능한 모든 출처가 확인된 hit만 받아들인 뒤,
같은 bank의 정확히 동일한 전체 본문을 먼저 묶는다. 유효한 출처의 ID·revision을
모두 남기고 가장 높은 기존 순위 점수를 유지한다. 그다음 대표 기억별 본문을
합치고 결과 제한을 적용한다. 다른 bank, 조건·부정·구두점이 다른 본문은
동일 근거로 합치지 않는다. 삭제된 출처가 포함된 hit는 중복 합산에 참여하지 않는다.

판단 임계값, reranker floor, 모델, 저장 정책과 기존 사용자 데이터는 변경하지 않는다.
이 결함이 과거 독립 평가 실패의 원인이었다고 확정할 수는 없다.

기존 private ledger·독립 평가 자료·Hindsight/ONNX 평가 런타임이 연결되지 않았다.
추가 공급자 호출은 0회이며 기존 ledger를 수정하거나 과거 cohort를 재채점하지 않았다.
연결된 환경에서 개발 검증과 독립 평가의 예산을 구분하고, 새 평가 실행 전
전체 197회 슬롯과 고정 입력을 확인해야 한다.

이후 필요한 작업은 새 독립 196건·40질문 평가, 실제 세 앱의 startup/resume/compact
검증, 최종 source와 배포 wheel·설치 소비의 동일성 확인, 원래 CI의 실제 통과다.
Core CI의 과거 결제/지출 한도 실패는 해결됐다고 확인하지 않았다.
현재 release 자산·tag·prerelease 표시는 변경하지 않았다.
