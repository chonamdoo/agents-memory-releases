# 0.3.0rc1 배포 경로

GitHub release asset upload가 현재 환경 인증에 HTTP 401을 반환했다. 릴리즈는 초안으로
유지하고, 검증된 파일을 같은 공개 저장소의 고정 커밋으로 먼저 게시했다. 설치기는
그 고정 파일의 SHA-256을 확인한다. 다른 자격 증명을 찾거나 네트워크 정책을 우회하지 않았다.

- 제품 검증 소스: `76f1a49134bb136bae1490c460f7afebb6fcc96f`
- 비공개 코어: `7160b548eb2940c079f86fcc793615742cc8ebd6`
- 동일 파일 게시: `8423de67191bbf664e0d4efd777f8537f8e77930`
- 번들 SHA-256: `82ea4927c311120cdeddf35aee736ecb19ff38055384f97f64ade66eab30b0cf`

`assets/SNAPSHOT.json`의 public_commit은 제품 코드를 검증한 커밋이다. 이후 공개 이력
병합은 트리 내용이 같음을 확인했다. 배포 파일 추가와 설치기의 다운로드 주소 변경은
공급자·기억 엔진·SDK·DB 스키마 변경을 포함하지 않는다. GitHub 공개 전의 이번 초안 태그를
최종 전송 주소가 들어 있는 커밋으로 확정하고, 실제 공개 URL에서 번들을 다시 내려받아
검사한다. 공개된 stable 태그는 변경하지 않는다.
