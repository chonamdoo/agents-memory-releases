# C3: 지원되는 Hindsight 키의 저장·전송 전 차단

2026-11-03(KST). 이 문서는 C53 당시 기록이다. 이후 현재 소스의 실제 실행과 점수는
[C54 검증](VERIFICATION-C54-CLOUD-SURROGATE.ko.md)·점수표를 따른다.
회사 Mac + Codex 대상 확인 이후 클라우드에서 가능한 검증을 진행했다.
현재 권장 후보는 c3이다. 코드 병합은 정식 배포가 아니며 최종 출시 조건을 완화하지 않았다.

## 반례와 수정

c1/c2의 로컬 키 검사 규칙이 같다는 것을 확인하고, 설치된 c2 wheel에 합성 Hindsight 키를
입력했다. `queued` 응답과 비공개 outbox에 원문이 남는 것을 재현했다. 이 항목은 drain하지
않았고 외부·모델 호출은 없었다. 서버 마스킹 성공 여부와 훅의 저장 전 차단은 별도 문제다.
원래 c1의 20개 backend 안전 시험 통과는 보존하면서 안전 준비 배점은 철회했다.

c3는 공식 Hindsight 키 문법의 일반·시스템·서명 형식을 같은 사전 검사에 추가했다. 새 입력은
로컬 payload를 쓰기 전에 거절하고, 이전 버전이 남긴 유효한 해시의 pending 항목도 선택 시
전체 내용을 재검사해 전송하지 않는다. 원래 민감 원문은 자동 삭제하거나 가리지 않고 보존한다.
이전 outbox는 작업을 재개하기 전에 별도 점검해야 한다. 미선택 항목을 주기적으로 전부
감사하는 기능이나 보편적인 비밀정보 탐지를 추가한 것은 아니다.

## 실제 확인

| 확인 | 결과와 범위 |
| --- | --- |
| 현재 코드 회귀 | 421개 고유 로컬 시험, 1,263개 setup/call/teardown 전부 통과. 실패·skip·xfail·xpass 0 |
| 설치된 wheel | 소스와 설치된 검사 모듈 바이트 일치. 3개 지원 키 형식의 짧은 입력·32 KiB 뒤 끝부분 등 6사례 모두 `sensitive_excluded`, payload 생성 0 |
| 기존 큐 | 맞는 SHA를 가진 과거 키 원문을 실제 drain에서 invalid로 처리, 전송 시도 0, 원문 보존 |
| 독립 Sol 검토 | 소스 digest·엄격 시험·wheel 일치 확인, Python/portable JavaScript 경계 35개 추가 확인. 범위 내 코드 차단 문제 없음 |
| 통신·환경 | 위 c3 설치본 시험의 네트워크 시도·모델 호출 0. Linux 격리 환경이며 실제 Mac/구독 CLI 성공 증거 아님 |

c2의 48 KiB 실제 모델 저장 성공과 64 KiB 다중 문서 진단은 이전 소스의 범위 증거로 남긴다.
그 실패 기록을 c3의 전체 통합·품질 통과로 바꾸지 않는다. 같은 저장 판단 모듈이라는 이유로
c1의 50개 실제 모델 결과를 c3에서 새로 실행한 것처럼 연결하지도 않는다.

## 점수와 종료 조건

권장 후보 소스가 바뀌었으므로 현재 그 소스에 결합한 핵심 회귀 15점만 인정한다.
**당시 개인 15 / 회사 15 / 공동 15점, 정식 배포 차단**이었다. 이는 정답률이 떨어졌다는 측정이
아니라 새 후보에서 아직 확인하지 않은 실행 증거를 합산하지 않는다는 뜻이다.
c1의 당시 개인 50점과 새 반례 후 35점은 [이전 기록](VERIFICATION-20261103.ko.md),
[철회 receipt](evidence/security-withdrawal-c52.json), 후보 history와 원래 evidence에 보존한다.

새 개선 후보 **2/3 사용**, 최종 독립 QA 확인 **0/1**이다. 회사 연결·실제 Mac은 사용자 지시로
뒤로 미뤘으며 통과 처리하지 않았다. 고정 100문항과 공식 읽기 전용 대조군은 준비됐지만
첫 답변·엄격 채점은 미실행이다. 64 KiB 다중 문서 묶음 수정·삭제도 다음 실제 통합 확인에
포함한다. 근거 없는 정책 단정·원문 유실·삭제 부활은 허용하지 않는다.

421개 시험이나 87개 문서 입력 허용으로 QA/SOTA를 주장하지 않는다. 남은 검증은 고정된
출시 표를 따르며 최대 후보 수를 소진한 뒤 연구나 튜닝을 무기한 반복하지 않는다. 정식 tag·
release·asset은 게시하지 않았고 GitHub CI도 실행하지 않았다.
