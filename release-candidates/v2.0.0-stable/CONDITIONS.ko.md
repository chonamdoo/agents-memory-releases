## 배포 검증 플랫폼

사용자 후속 지시(2026-11-08 KST)에 따라 **macOS 검증은 정식 배포 필수 조건에서
제외한다.** macOS는 사용자가 직접 시험하며 그 결과를 기다리지 않고 나머지
조건이 모두 충족되면 검증한 Linux 범위의 MCP 정식판을 배포한다. macOS를 검증
완료나 정식 지원으로 표시하지 않는다.

현재 배포 검증 범위는 **Ubuntu 24.04·Linux x86_64·glibc 2.39**, Python 3.12와
3.13이다. Debian 12·glibc 2.36의 pgvector 로더 실패는 보존하고 지원으로
표시하지 않는다. Darwin 전용 검사 5개는 미실행 이력으로 남기되 Linux 정식
배포를 차단하지 않는다. 독립 라벨·저자 사전 승인·질문 변경·품질·안전·자원·
호출 한도와 Linux의 설치·업데이트·rollback·미전송 작업 보존 조건은 유지한다.

## 승인된 독립 AI 검증과 과거 자료의 한계

사용자는 서로의 결과를 보지 않는 두 독립 AI 검증자를 승인했다. 새196건·원본40질문의 분류·관련성 원시 κ는 모두1.00, 질문 변경0건이며 각자가 작성한 해시 결합 사전 승인을 검증했다. 이를 사람 라벨이나 모집단 성능으로 부르지 않는다. Core PR75에 제품 추론 전에 원본 라벨·검토 기록·승인을 고정했다. 최종 실행 런타임 등록과 실제 품질 평가는 별도 단계다.

사용자 지시 **“누락 6개를 공개하고 새 독립 평가 진행”**에 따라 이번 최초 정식 전환 작업(실패한 v2.0.3 후보와 이를 수정한 MCP v2.0.4)에 한해 과거 원본6개 대조만 출시 필수조건에서 제외한다. [정확한 역할·해시와 승인 범위](../v2.0.3-independent/REFERENCE-AUTHORIZATION.json)를 공개한다. 확보된528참조는 전수 대조했고 정확히 같은 텍스트는0건이다. 누락6개는 미검증이며 전체 과거 비중복을 입증한 것이 아니다. 소진 코호트 거부·원래 실패 보존·다른 품질·안전·자원·호출 조건은 유지한다.
