# MCP 2.0.4 검색 수정 후보

현재 정식 배포 전입니다. Core/SDK 버전2.0.0의 정확한 바이트는 [CANDIDATE.json](CANDIDATE.json)과 [SHA256SUMS](SHA256SUMS)에 고정합니다. SDK는 Native 지명 뒤 승인 원문의 명시 주제를 확인하고, 불명확하면 기존 semantic 결과를 유지합니다. 상위3개 고정·골드목록·주제명 하드코딩이나 Native0.003 floor 변경은 없습니다.

앞선 독립196/40은 저장80/80·자동40/40·검색필수근거40/40이나 잡음80/200으로 실패했습니다. 그 자료는 진단용으로만 보존하며 새 독립 검증을 대신하지 않습니다. 새196/40 자료의 독립 AI 두 명 라벨·최종 후보 사전 승인을 검증했고 [해시를 사전 등록](INDEPENDENT-V2-PREREGISTRATION.json)했습니다. 새 실제 평가는 저장80/80·자동39/40·Hit@5 40/40·필수 근거 전체39/40·검색 잡음0/119로 측정된 기준을 통과했습니다. [검증 결과와 한계](live-quality-v2/README.ko.md)를 확인하세요. 실제 Claude 수명주기36/36도 통과했지만 Codex는 작업공간 조회에서 중단됐고 OMP 실검증은 남아 있습니다. [전체 출시 판정](../v2.0.0-stable/STATUS.json)은 아직 미통과입니다. 원래 과거6개 미확인 공개 범위·다른 품질/안전/자원/호출 조건은 유지합니다.

설치는 [공통 설치 안내](../../distribution/server/README.ko.md#로컬-설치-claudecodexomp)를 따르세요. 현재 마켓 설치가 정식 품질 통과를 뜻하지 않습니다.
