# MCP 2.0.4 검색 수정 후보

현재 정식 배포 전입니다. Core/SDK 버전2.0.0의 정확한 바이트는 [CANDIDATE.json](CANDIDATE.json)과 [SHA256SUMS](SHA256SUMS)에 고정합니다. SDK는 Native 지명 뒤 승인 원문의 명시 주제를 확인하고, 불명확하면 기존 semantic 결과를 유지합니다. 상위3개 고정·골드목록·주제명 하드코딩이나 Native0.003 floor 변경은 없습니다.

앞선 독립196/40은 저장80/80·자동40/40·검색필수근거40/40이나 잡음80/200으로 실패했습니다. 그 자료는 진단용으로만 보존하며 새 독립 검증을 대신하지 않습니다. 새196/40 자료의 독립 AI 두 명 라벨·최종 후보 사전 승인을 검증했고 [해시를 사전 등록](INDEPENDENT-V2-PREREGISTRATION.json)했습니다. 실제 품질 평가는 아직 실행 전입니다. 원래 과거6개 미확인 공개 범위·다른 품질/안전/자원/호출 조건은 유지합니다.

설치는 [공통 설치 안내](../../distribution/server/README.ko.md#로컬-설치-claudecodexomp)를 따르세요. 현재 마켓 설치가 정식 품질 통과를 뜻하지 않습니다.
