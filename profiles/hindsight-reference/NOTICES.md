# Scope and third-party notices

This bundle contains maintainer-authored configuration, documentation and sanitized validation metadata.
It does not redistribute the private agents-memory implementation, Hindsight implementation, Python wheels,
model weights/tokenizers, native binaries or their dependency graph. Existing Native release notices remain
in the parent distribution repository and apply to that older binary, not a newly bundled runtime here.

Hindsight upstream is MIT: https://github.com/vectorize-io/hindsight/blob/14e7306e27cdbd03ad5f17cf46f22a5f6d6ec5a2/LICENSE
Obtain and review runtime/model dependency licenses separately when preparing your installation.
No license or redistribution permission for an unverified model/dependency is inferred from the
application's license. Source/model SHA-256 identifiers are integrity references, not signatures.
